# Семантический поиск товаров

MVP поиска товаров по текстовому запросу. В проекте сравниваются TF-IDF, семантический поиск на intfloat/multilingual-e5-small и гибридный поиск RRF.

Работа выполнена для категорий «Одежда» и «Обувь». Подготовленный каталог содержит 48376 карточек, каталог оценки — 4256 карточек из пула асессоров.

## Результаты
Лучшей конфигурацией стал E5-small с текстом:
название + предметная категория + бренд + описание.

| Набор | Запросов | NDCG@10 | Recall@10 | MRR@10 | Precision@5 |
|---|---:|---:|---:|---:|---:|
| Golden-сет, train | 700 | 0,5633 | 0,7674 | 0,6867 | 0,2711 |
| Финальный test | 300 | 0,5696 | 0,7828 | 0,6477 | 0,2467 |

Порог релевантности — 2. Проверяемые K: 1, 3, 5, 10.
NDCG использует исходную шкалу релевантности 0–3.
Неразмеченные товары при расчёте метрик считаются нерелевантными.

Полные результаты, эксперименты и ограничения приведены в ноутбуке и рабочем документе.

## Установка
Команды ниже предназначены для PowerShell в Windows.

```powershell
git clone https://ds-practicum.gitlab.yandexcloud.net/s20436636/semantic-search-project.git
cd semantic-search-project
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip check
```

Если репозиторий закрыт, потребуется авторизация в учебном GitLab.

## Настройка доступа
Создайте файл .env в корне проекта:

```dotenv
AWS_ACCESS_KEY_ID=<ключ доступа к S3>
AWS_SECRET_ACCESS_KEY=<секретный ключ S3>
S3_ENDPOINT_URL=https://storage.yandexcloud.net
S3_SOURCE_BUCKET=<имя исходного бакета>
MLFLOW_TRACKING_URI=<полный адрес учебного MLflow с https://>
MLFLOW_TRACKING_USERNAME=<логин MLflow>
MLFLOW_TRACKING_PASSWORD=<пароль MLflow>
MLFLOW_S3_ENDPOINT_URL=https://storage.yandexcloud.net
```

Замените значения в угловых скобках параметрами из учебной среды.
Для сохранения артефактов необходим доступ на запись в бакет, используемый MLflow.

Файл .env не должен попадать в репозиторий.

## Данные
Используются четыре файла:
- wb_products_raw_sample.parquet — исходный каталог.
- wb_products_dedup.parquet — список карточек пула асессоров.
- queries_synthetic_train.parquet — тренировочная разметка и golden-сет.
- queries_synthetic_test.parquet — финальная тестовая разметка.

Ноутбук скачивает необходимые файлы из S3 в data/, если их ещё нет.
Доступ к исходным данным предоставляется учебной платформой.

## Запуск ноутбука
1. Откройте папку проекта в VS Code.
2. Откройте semantic_search_project.ipynb.
3. Выберите ядро .venv с Python 3.12.5.
4. Выполняйте ячейки последовательно сверху вниз.

В ноутбуке выполняются:
- загрузка и проверка данных;
- EDA и подготовка каталога;
- построение TF-IDF и эмбеддингов E5-small;
- оценка baseline на golden-сете;
- три эксперимента: добавление бренда, удаление описания, RRF;
- финальная оценка выбранной конфигурации;
- сохранение результатов в MLflow;
- качественный анализ и итоговые выводы.

При первом запуске модель загружается с Hugging Face.
Эмбеддинги сохраняются в artifacts/. Повторное выполнение ячеек model.encode пересчитывает их.

Тестовый блок управляется переменной RUN_FINAL_TEST_EVAL.
При воспроизведении итоговой оценки используйте True. Не используйте результаты test для подбора параметров или выбора конфигурации.

Ячейки логирования создают новые запуски MLflow при повторном выполнении. Для просмотра готовых результатов достаточно сохранённых выводов ноутбука.

## MLflow
Название эксперимента: semantic_search_project.

В эксперименте сохранены шесть успешных запусков:
- tfidf_baseline;
- e5_baseline;
- e5_brand;
- e5_short;
- tfidf_e5_rrf;
- e5_brand_final_test.

Каждый запуск содержит параметры, метрики и артефакты оценки.
График и общая таблица сравнения дополнительно сохранены в e5_brand.

Метрика mrr соответствует MRR@10; ограничение указано параметром mrr_cutoff=10.

Проверка из корня проекта:

```powershell
.\.venv\Scripts\python.exe check_mlflow.py semantic_search_project --env-file .env --min-runs 6
```

Для проверки сервер MLflow должен быть включён в учебной платформе.

## Ограничения и рекомендация
Разметка синтетическая и неполная. Каталог оценки меньше полного каталога, поэтому полученные метрики нельзя напрямую переносить на промышленный поиск.

Рекомендуется пилот E5-small с добавлением бренда, дополнительная разметка реальных запросов и проверка фильтров по атрибутам. Перед внедрением необходимы измерение задержек и A/B-тест.

Streamlit-приложение не реализовано: это дополнительная часть задания.
